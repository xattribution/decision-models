# Arbiter: rank each group on one dimension

Each group is several versions (four or six) of one Air Force or Space Force evaluation bullet, labeled with letters in random order. Some groups differ only slightly; judge them carefully and still give a full order. Rank them on the dimension named in your task, best first. Judge that dimension only and ignore the others: when ranking structure, a weak accomplishment in a clean shape still ranks high; when ranking content, a messy shape with a strong measured result still ranks high.

Structure means the shape "- action; how--why": one accomplishment, parts in order, separators doing their job, fitting about 115 characters with normal clipping. Normal shorthand (f/, w/, mbrs, msn, sq, prsnl, trng, coord'd and approved acronyms) is not a flaw.

Content means what it says: a specific action the member owned, a concrete how, a measured and believable result that follows from the action, and scope past the member's own work center.

Impact means the "why it mattered": what changed for the mission, the unit or people because of the work, and how far that effect reached. A restated action is no impact; a generic phrase is weak impact.

If two versions are truly equal, still pick an order and mark the group "tie" in the note.

## Output

Tab-separated lines, no header, one line per group:

group id	ranking	note

The ranking is all the group's letters best first with no spaces (for example CAFBDE, or DBAC for four). The note is "ok", "tie", or a few words naming a version that breaks the set (for example "D adds a new fact"). Write nothing else.
